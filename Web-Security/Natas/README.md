# OverTheWire — Natas

[OverTheWire Natas](https://overthewire.org/wargames/natas/) is a web security wargame designed to introduce web application vulnerabilities through practical challenges.

It focuses on understanding how web applications work and how common security weaknesses can be identified and exploited.

Throughout the challenges, you'll encounter concepts related to HTTP, HTML, PHP, cookies, authentication, input handling, and server-side security.

I am currently working through Natas to build a stronger foundation in web application security and penetration testing.

## What I'm Learning

Through the Natas challenges, I'm developing practical knowledge of:

- **HTTP Fundamentals:** Understanding requests, responses, headers, and methods.
- **Web Technologies:** Exploring HTML, PHP, and how server-side applications work.
- **Cookies & Sessions:** Understanding how web applications manage client state.
- **Input Handling:** Analyzing how user-controlled data is processed by applications.
- **Web Vulnerabilities:** Identifying weaknesses such as Local File Inclusion (LFI) and Command Injection.
- **Authentication & Access Control:** Exploring how applications handle identity and permissions.
- **Source Code Analysis:** Reading application code to understand its behavior and identify potential security flaws.
