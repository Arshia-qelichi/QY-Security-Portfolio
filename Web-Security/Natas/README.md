# OverTheWire — Natas

[OverTheWire Natas](https://overthewire.org/wargames/natas/) is a web security wargame designed to introduce web application vulnerabilities through practical challenges.

It focuses on understanding how web applications work and how common security weaknesses can be identified and exploited.

Throughout the challenges, you'll encounter concepts related to HTTP, HTML, PHP, cookies, authentication, input handling, and server-side security.

I am currently working through Natas to build a stronger foundation in web application security and penetration testing.
