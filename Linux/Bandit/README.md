# OverTheWire — Bandit

[OverTheWire Bandit](https://overthewire.org/wargames/bandit/) is a hands-on Linux wargame designed to teach the basics of Linux through practical challenges.

It covers essential concepts such as command-line navigation, file permissions, SSH, text processing, and working with Linux utilities.

I completed all 27 levels, using the challenges to strengthen my Linux fundamentals and develop a more practical understanding of working in a command-line environment.

## What I Learned

Throughout the 27 levels, I practiced and strengthened my understanding of:

- **Linux Navigation & File Management:** Working with directories, hidden files, and file discovery.
- **File Permissions:** Understanding Linux permissions and privilege-related concepts.
- **Text Processing:** Using tools like `grep`, `sort`, `uniq`, `strings`, and `find` to analyze files and extract information.
- **SSH & Remote Access:** Connecting to remote Linux systems and working through terminal sessions.
- **Processes & Cron:** Understanding running processes and scheduled tasks.
- **Git Basics:** Exploring repositories, commits, and Git history.
- **Shell Behavior:** Understanding restricted shells and basic shell escape techniques.
