# OverTheWire — Bandit

[OverTheWire Bandit](https://overthewire.org/wargames/bandit/) is a hands-on Linux wargame designed to teach the basics of Linux through practical challenges.

It covers essential concepts such as command-line navigation, file permissions, SSH, text processing, and working with Linux utilities.

I completed all 27 levels, using the challenges to strengthen my Linux fundamentals and develop a more practical understanding of working in a command-line environment.
